## 尚需目标设备验收

没有用户的Windows Server 2025 / E3-1275 v3，也没有Chromecast with Google TV 4K实机，不能确认该核显驱动、实机局域网广播、遥控器键值、长期播放与系统省电行为。默认720p/auto/单路；QSV启动探测失败会回退CPU，1080p受本机≥1.3倍实时测速门槛限制。

官网有短时或持续403的剧集，本版不保证全片库随时可用。正常来源失败会提供重试/返回，不显示虚构节目、不切换到演示样片，也不再要求手机注入。

当前云环境只有2个CPU配额且没有/dev/kvm；首次Android构建与TV模拟器软件启动会争用CPU。早期整集HLS验证因过短的180轮等待上限超时；随后增加有界等待并限制解码/滤镜/编码线程，CPU使用superfast预设，完整验证通过。上述云环境耗时不能当成用户E3实测。

## 复现

```sh
npm test --prefix server
node --use-env-proxy server/scripts/prepare-player.mjs
node --use-env-proxy tools/verify-lan.mjs --real-source
```

第三条会访问真实官网并暂存一集，结束清理临时媒体；仅写脱敏的集数、耗时和解码结果。普通服务端单元测试不请求真实官网，也不需要用户账号。

Android TV 14 官方x86镜像已实际尝试软件启动；当前环境没有硬件加速，约25分钟的有界尝试仍未完成系统启动，ADB始终offline，内核日志停留在系统odsign/ART初始化。未安装或运行本项目APK，因此不能把这个结果宣称为TV运行通过，也没有证据判定为客户端故障。已结束该测试模拟器，未操作用户手机。

# 红果 TV（电视端 0.1.0 / 服务端 0.1.1 账号预览）

非官方的家庭局域网客户端：Android TV 14 / Chromecast with Google TV 4K 上运行轻量原生界面，Windows Server 负责单路 H264/AAC 转码。保留完整画面，竖屏剧集左右留黑边。

已实现首页、四类目录与分页、榜单、搜索、完整选集、自动下一集、暂停/快进/快退、本机收藏、历史与逐集续播。首次连接支持局域网发现和六位码配对，也可手动输入服务器地址。电视切到后台或返回详情会释放服务器播放任务。

## 安装与使用

1. 将 `hongguo-tv-windows-0.1.0.zip` 解压到 Windows Server 的固定目录；双击 `windows/setup.cmd`，首次需要联网下载 Node.js、FFmpeg 和官网公开播放器组件，均验证 SHA-256。
2. 双击 `windows/start.cmd`，保持窗口运行，记录显示的局域网地址和六位配对码。
3. 将 `hongguo-tv-0.1.0.apk` 安装到 Chromecast；打开“红果 TV”，选择发现的服务器或输入上述地址，再输入配对码。
4. 若电视找不到服务器，可手动填写 `http://服务器局域网IP:8751`。若连接仍受 Windows 防火墙阻挡，可按 [Windows 说明](windows/README.zh-CN.md) 手动添加仅限“专用网络/本地子网”的规则。服务端默认不自动提权，不修改防火墙。

服务器和电视需在同一可信家庭局域网；该版本不用于公网部署。默认匿名播放无需账号。可选的服务端官网账号登录需要用红果 App 扫码，详见 [账号预览版更新说明](docs/ACCOUNT.zh-CN.md)。无需 root、ADB 或手机采集；之前的注入工具保持停用。

## 这台服务器的设置

针对 E3-1275 v3 / 核显 / 16GB 的默认设置为 **720p、auto 编码器、单路播放**。启动时实际测试 Intel QSV，不能使用时回退到 libx264。没有假定 Haswell 核显在 Windows Server 2025 上一定有可用驱动。

需要 1080p 时，先停止服务，运行 `windows/benchmark.cmd`，提供不少于 20 秒的本机真实视频。仅当相同硬件与编码器在最近 30 天的实际 1080p 测速达到 1.3 倍实时，1080p 设置才会生效；否则启动会自动使用 720p。测速不会自动更改用户配置；选择方式见 Windows 说明。尚未对用户的 E3 或 Chromecast 实机做性能验收。

## 播放来源与已知限制

播放使用指定官网提供的目录、播放信息及其公开软件播放器协议，播放器组件按固定版本下载和校验；不修改原版 App，不使用手机注入，不导出内容密钥。仅在内存/进程管道中传递官网本次返回的播放参数。

- 《军需处长的账本》第 1、24、46 集已完成 720p 整集解码；《夜晚的答案》第 1、16 集也已通过。后者末集在正常请求中仍返回 `protected_playback_unavailable`，不能保证所有剧集随时可用。来源暂不可用时显示错误并允许重试，不把目录集数当成播放成功。
- 本版先准备整集，再输出 HLS；首次启动和换集需要等待下载/处理，缓存中的同集跳转较快。只保留最多三集、约 1GB、15 分钟的短期缓存；停止服务清理，启动也会清理遗留临时媒体，不提供离线下载。
- 搜索支持官网 JSON 接口分页与电视端逐页加载；搜索排序/总数可能随请求变化，跨页可能重复，去重后仍不声称取得全部匹配项。官网版本或数据结构改变时需要更新适配；校验失败不会跳过验证执行新播放器。
- 收藏、历史与进度只保存在电视本机。服务端可选登录红果官网账号，尚未接入云收藏、金币、广告奖励、评论或原版 App 的设备服务。

验证范围和剩余实机验证见 [测试记录](docs/VALIDATION.zh-CN.md)，API 见 [接口契约](docs/API.md)。

## 源码与分析

- `client/`：Kotlin 原生 View/RecyclerView + Media3，minSdk 26、target/compileSdk 35；APK 是自签名测试版。
- `server/`：Node.js 24，无 npm 第三方运行依赖；FFmpeg 独立进程转码。
- `windows/`：本目录运行库下载、启动/停止、测速、可选当前用户登录任务；不写系统 PATH。
- `research/ANALYSIS.zh-CN.md`：原版 APK 的 REA 静态证据与覆盖边界。原版 7.4.1.32 有 25 DEX；整包 JADX 曾超时，后续只对选定路径建立分析载体，不是整包反编译完成。
- `research/protocol-pass2/README.zh-CN.md`：官网软件播放协议与实际完整解码记录。

源码构建方式见 [客户端说明](client/README.md)；服务端测试运行 `npm test --prefix server`。外部组件及许可见 [DEPENDENCIES](docs/DEPENDENCIES.md)。

# 第二轮协议与完整播放验证

日期：2026-10-21 UTC。此轮继续使用 REA 定点分析原 APK，同时在独立云环境调查指定官网的正常播放器，不再操作用户手机。

## 已回答的关键问题

原先已确认 CENC 加密，却未完成软件播放路径验证。官网 `t.78fb905b21.js` 将 `play_info.player_access_key` 交给 DASHPlugin，设置 `useEME:false`、`useUnionInfoDRM:false`、`playInfoType:"TOP"`。公开 `m.ad3954075c.js` 内含其正常软件 worker。使用原样 worker 的 `updateValue`、`decryptHeader`、`decryptBody` 消息可获得用于常规播放的媒体数据，不需要 CDM 或修改原版 App。

研究适配器 `web-player/sdk_bridge.cjs` 把正常浏览器 worker 消息映射到 Node worker_threads；音频、视频各用独立 worker。访问参数仅通过 stdin 传入内存，不导出展开后的密钥。媒体文件名称含 `.private.`，仅保留本地研究，不进入交付包。
